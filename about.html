SAVE 01 1997

初始存档 · 首次登录

玩家接入《世界 Online》，成功登陆地球服务器，随机出生在中国·江苏，角色创建完成。

出厂设置不由我选，后面的路由我选。

⚙️
SAVE 02 2015

新手村 · 专业随机分配

成功解锁大学副本，但由于缺乏新手攻略，被系统随机分配到【机械专业】。在不喜欢的地图里，一待就是四年。

四年只确认了一件事：这条路不是我的。

🧭
SAVE 03 2019（上）

毕业分支 · 寻找新路线

系统推荐职业：【暖通工程师】。玩家没点确认，自学互联网，投出第一批简历。唯一掉落的任务是 4000 元的产品经理实习，评估投入产出比后，玩家决定放弃接取。

敢说"不值"，是给自己定价的第一步。

📚
SAVE 04 2019（下）

闭关副本 · 三跨考研

放弃工作副本，转入学业支线。闭关一年，挑战跨专业、跨学校、跨地区的 211 师范研究生副本。国家线已通过，专业线差一口气，副本挑战失败。

没通关的副本，也掉了经验值。

💼
SAVE 05 2020

读档重来 · 主线开启

重新进入求职地图，正式接取【公众号运营】主线任务。角色面板解锁常驻数值条【物质生存条】，从此需要自主维护资源收支。

绕了一年远路，反而走对了方向。

🎬
SAVE 06 2022

隐藏任务 · 0 经验转职

玩家判断短视频版本更强势：白天跑公众号主线，下班偷偷刷短视频技能树。在相关岗位经验为 0 的情况下，成功解锁新职业：【短视频编导】。从此，职业主线正式切换。

机会不等人，但准备好的人接得住。

🏆
SAVE 07 2025

满级输出 · 主线高光

在短视频副本持续开荒刷怪，职业状态持续升级，帮多个账号从 0 起号，月薪最高突破 4 万，累计内容播放量破亿。

上天会引领你去最适合的那条路。

📍
